# Step Six - Webserver Setup

Finally, we need to configure a webserver to expose Jexpanel.

## Choosing an appropriate webserver
For most people, the default option will be `nginx` as it is installed in Step One. If you don't have
other websites on your system running on different webservers, like `apache` or `caddy`, choosing NGINX
will be the easiest route. However, if you are currently using any other webserver, follow the appropriate guide.

### Option 1: Use NGINX (recommended)
Instructions on how to configure NGINX can be found [here](/docs/intro.md).

### Option 2: Use Apache
Instructions on how to configure Apache can be found [here](/docs/intro.md).

### Option 3: DirectAdmin
Instructions on how to configure DirectAdmin can be found [here](/docs/intro.md).
