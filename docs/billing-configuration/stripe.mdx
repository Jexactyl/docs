# Billing with Stripe

In this guide, we will explain how to add Stripe billing to Jexpanel.

:::warning
Make sure your application is in 'Test Mode' before accepting live payments.
You can do this by flicking the toggle for test mode in the Stripe dashboard.
:::

### Enable billing module in Jexpanel
Start by logging into Jexpanel, then navigate to `Admin > Modules > Billing`.
Then, if the module is disabled, click 'enable billing module' button.

Once the module is enabled and your store is live, you&apos;ll need to add your Stripe
API keys. At the moment, there is no way to do this through the UI - you&apos;ll need to 
log into your webserver and add the keys to the `.env` file yourself.

### Add stripe public & private key to `.env`
When you are logged into your system, run:
```bash
nano /var/www/jexactyl/.env
```
Then, at the bottom of the file, add:
```bash
STRIPE_KEY=pk_test_......
STRIPE_SECRET=sk_test_......
```

### Create categories and products
Then, navigate back to the admin billing UI and start adding products and product categories
in the 'Products' tab. Define custom prices, server resource limits and more before continuing.

### Make a test payment
With your application still in test mode, go to the client UI, then `Billing > Store > Plan Name`.
Then, you&apos;ll be prompted to enter your billing details and checkout.
:::tip
Make sure you have already configured a node, added allocations to it, and that it's online.
:::

### Switch Stripe to production mode
Once you've confirmed payments are successful, you can go back to Stripe and get new API keys
for 'Live' mode, and overwrite your existing test keys stored in `.env`.
